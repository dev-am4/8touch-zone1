# Video assets

วางไฟล์วิดีโอจริงในโฟลเดอร์นี้โดยใช้ชื่อ:
- idle.mp4 — Idle Loop 60–90 วินาที
- heart.mp4 — หัวใจ ~25 วินาที
- lungs.mp4 — ปอด ~25 วินาที
- brain.mp4 — สมอง ~25 วินาที
- digestive.mp4 — กระเพาะและลำไส้ ~35 วินาที
- liver.mp4 — ตับ ~25 วินาที
- kidney.mp4 — ไต ~25 วินาที
- muscle.mp4 — กล้ามเนื้อและกระดูก ~25 วินาที
- mouth.mp4 — ช่องปากและฟัน ~25 วินาที

แนะนำ MP4 / H.264, AAC 48 kHz และความละเอียดตรงกับพื้นที่ฉายจริง
Idle ควร loop ได้เนียน และเฟรมแรก/ท้ายของคลิปย่อยควรเหมาะกับการ crossfade

ถ้ายังไม่มีไฟล์วิดีโอ ระบบจะแสดง fallback visualization เพื่อทดสอบ interaction ได้ก่อน
