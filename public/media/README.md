# Preview media

Place the approved main loop here as:

`public/media/idle.mp4`

Web Preview loads this file full-screen and muted for reliable autoplay.

Final Electron Kiosk uses the same filename from the external local SSD folder:

`media/idle.mp4`

Do not rename the eight Story files:
`brain.mp4`, `mouth.mp4`, `lungs.mp4`, `heart.mp4`, `liver.mp4`, `kidney.mp4`, `digestive.mp4`, `muscle.mp4`.
